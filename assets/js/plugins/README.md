# Plugins

Bootstrap 5.3 and Chart.js 4 load from the jsDelivr CDN.
To self-host, download them here and update the `<script>` tags:

- bootstrap.bundle.min.js — https://getbootstrap.com/docs/5.3/getting-started/download/
- chart.umd.min.js — https://www.chartjs.org/docs/latest/getting-started/installation.html
